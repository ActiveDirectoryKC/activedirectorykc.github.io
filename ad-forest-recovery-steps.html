Manual Active Directory Forest Recovery Steps
Fully manual = No tools to help
Scritable w/native tools (PowerShell, etc.)
Purpose-built tools shine
1.Disable network to/from DCs.
2.Connect new/restored DCs to private network + someone has to setup a private VPN
For each domain:
3.Nonauthoritative restore of first writeable DC
4.Authoritative restore of SYSVOL on that first DC
5.Cleanup malware...
6.Roll all admin account passwords
7.Seize FSMO roles
8.Metadata cleanup of all writeable DCs NOT restored yet.
9.Setup DNS on the forest root DC (if using ADI DNS)
10.Remove the global catalog from each DC ⏱(wait for GC to be removed)
11.Delete DNS NS records of DCs that are gone
12.Delete DNS SRV records of DCs that are gone
13.Jump the RID pools by 100K
14.Invalidate the current RID pool for every DC
15.Reset the computer account of the root DC 2x
16.Reset krbtgt account twice (starter forest begins here)
17.Setup Windows Time
18.Nonauthoritative restore of other DCs in the domain
19.Add GC on a DC for each OS version in domain ⏱(wait for GCs to create)
20.Take a backup of all DCs in the starter forest
21.Create an IFM package for each OS version in each domain (option, but can speed stuff up)
22.Build out new forest with more DCs to support admin/server admin operations
For each DC to be repromoted:
23.Clean up gone DC using /FORCEREMOVAL or rebuild OS
24.Copy IFM package to server ⏱(Wait...) (Secure this!)
25.Take the DC off the public net and put it on the new forest network
26.Run a DCPROMO / DCPROMO IFM ⏱(all domains going to take days. may get basics running here.)
27.Verify forest health
28.Move new forest to the corp network
29.Reboot all servers and clients in forest to communicate with new forest
Important Considerations

Manual recovery is error-prone

Mistakes are bound to happen. However, mistakes force starting over from scratch which means more time!

Native Tools Suck

Native tools only help with individual steps — none connect everything. Most don't support multi-domain/forest very well.

Lots of Hands Make Confusing Work

Core identity/AD team, ops at every datacenter, + external support. Estimated 10–15 IT staff in an avg. enterprise.

Time reality

Days to weeks without purpose-built tooling. Every hour AD is down is every hour your business is down.

Months to Never if backups get compromised/don't exist.
