A place to point people when they ask "where do I start with Active Directory?" and "what tools should I be looking at?"

This is built from the [r/ActiveDirectory wiki](https://www.reddit.com/r/activedirectory/wiki/index), which the subreddit's moderators maintain with suggestions from the community. The Reddit wiki is the version the mods work from. A backup copy lives in [GitHub](https://github.com/ActiveDirectoryKC/RedditADWiki), and this site is the readable, searchable version of it.
